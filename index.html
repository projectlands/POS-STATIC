Koneksi Database Eksternal Lokal Saja

Pilih Google Spreadsheet, MySQL / MariaDB, atau Firebase Firestore

Status: Database Lokal Saja

PIN Auth Wajib

Saat terhubung ke database online (MySQL, Spreadsheet, atau Firebase), autentikasi peran (Kasir & Admin) otomatis aktif untuk melindungi laporan, stok, dan pengaturan.

Jika dinonaktifkan, aplikasi berjalan sepenuhnya offline di memori lokal (IndexedDB)
Panduan Google Spreadsheet:

1. Buat Spreadsheet baru di Google Drive.
2. Buka Extensions > Apps Script, paste script dari file google-sheets-script.js yang sudah kami siapkan di folder proyek.
3. Klik Deploy > New Deployment > Web App (Who has access: Anyone), lalu salin URL Web App ke bawah ini.

Panduan MySQL / MariaDB via REST API:

Browser memblokir koneksi langsung raw port 3306. Gunakan file bridge api.php yang sudah kami sediakan di root folder. Letakkan file api.php di web hosting / Laragon / XAMPP Anda. Tabel MySQL akan otomatis terbuat saat pertama kali terhubung.

Sinkronisasi Manual Menyeluruh

Gunakan tombol di bawah untuk mencadangkan seluruh data lokal ke database aktif atau mengunduh data dari database online ke HP ini.
