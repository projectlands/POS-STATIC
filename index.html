Sinkronisasi data online gratis via Firebase Firestore

Status Sinkronisasi
Firebase belum dikonfigurasi. Ikuti panduan di bawah untuk menghubungkan akun Firebase gratis.
Cara Mendapatkan Firebase Config Gratis (Klik untuk lihat)

1. Buka Firebase Console (masuk dengan akun Google Anda).

2. Buat Project baru (misal: POS-Static), klik Lanjut.

3. Di menu kiri, pilih Build > Firestore Database, klik Create Database. Pilih lokasi terdekat (misal Jakarta / Singapore), dan pilih mode Start in test mode.

4. Buka Project Overview > klik ikon Web </> untuk daftarkan Web App.

5. Salin blok kode firebaseConfig = { ... } lalu tempel ke kotak di bawah untuk ekstrak otomatis!
